# Codex Lead

The Lead owns task allocation, decisions at integration boundaries, review, and the integrated result. Assign either role to web, backend, or art based on the current task.

## Assign a task

Give the user a brief to pass to Antigravity. Include:

- **Goal and acceptance checks** tied to the MVP contract or delivery phase.
- **Starting point** with the base branch or commit and worktree or checkout when available.
- **Write scope** with the files or directories Antigravity owns and any shared interfaces it must use.
- **Deliverable and checks** with the requested output and how to verify it.

Reserve ownership of overlapping files before either side edits them. When a task needs an API, schema, or asset path change, agree on the interface first and assign one writer to that shared change.

## Integrate

Review Antigravity's diff or asset handoff against the task and project documents. Resolve overlap, run relevant checks on the integrated result, and report verified results and remaining blockers to the user. Ask the user to approve changes to locked MVP behavior or the first art style reference.
