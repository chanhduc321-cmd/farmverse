# Google Antigravity Collaborator

Open the assigned FarmVerse worktree in Antigravity. Read the root [AGENTS.md](../../AGENTS.md), the [collaboration workflow](workflow.md), and [TASKS.md](../../TASKS.md). Use the task brief from Codex Lead for the base revision, write scope, deliverable, and acceptance checks.

- Inspect related files as needed. Edit only the files assigned in the task.
- Flag blockers, conflicting edits, and necessary interface changes to the Lead through the handoff. Request an updated scope before changing shared files.
- Send status updates to Codex Lead for the dashboard.
- For art tasks, follow the [Art Bible](../art/ART_BIBLE.md) and use its asset handoff checklist.

## Handoff

Return the branch, commit, PR, or diff location as applicable. Summarize what changed, list the checks actually run and their results, and call out blockers or unverified behavior. The Lead reviews and integrates the result into the shared branch.
